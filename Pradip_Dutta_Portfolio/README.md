# Pradip Dutta — Portfolio

A responsive single-page developer portfolio built from the public information available on Pradip Dutta's GitHub profile and the five Unstop certificate links supplied for the portfolio.

## Run
Open `index.html` in a browser.

## Customize
- Update project descriptions in `index.html`
- Replace the generic certificate titles with the exact certificate/event names if desired
- Add real project links when repositories are published
- Add a profile photo or resume if desired
